Bienvenue dans votre application de bloc-notes minimaliste et élégante. Cette version met l'accent sur une interface utilisateur épurée avec un thème sombre/clair bien intégré.

## ✨ Fonctionnalités Principales
- 🌗 **Thème Sombre/Clair Dynamique** : Bascule automatique basée sur les préférences système ou via un bouton dédié.
- 📝 **Interface Glassmorphism** : Utilisation d'un style verre pour l'interface de saisie.
- 💾 **Persistance des Données** : Les notes sont sauvegardées dans le `localStorage` du navigateur.
- 📱 **Responsive** : Conçu avec Tailwind CSS pour une excellente ergonomie sur tous les appareils.

## 🛠️ Stack Technique
- **HTML5** : Structure sémantique.
- **Tailwind CSS (CDN)** : Styling utilitaire.
- **JavaScript (ES6+)** : Logique de gestion des notes et du thème.

## 🚀 Démarrage Rapide (Local)

1. **Ouvrir** le fichier `index.html` dans votre navigateur web.

## 🗄️ Gestion des Thèmes
Le thème est initialisé en fonction des préférences système (`prefers-color-scheme: dark`). Il est ensuite stocké dans `localStorage` pour maintenir le choix de l'utilisateur entre les sessions.
